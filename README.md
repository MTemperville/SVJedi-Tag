
# SVJedi-Tag

**SVJedi-Tag** is a structural variant genotyping tool designed to genotype inversions from linked-read sequencing data. It leverages the barcode signals specific to linked-read technology and combines them with a genotype likelihood model to estimate the genotype of a sample for a set of target inversions.

SVJedi-Tag first constructs a variation graph from the reference genome and a set of structural variants, including the target inversions as well as nearby structural variants that may affect genotyping accuracy (e.g., variants located close to inversion breakpoints). Linked reads are then aligned to the variation graph using VG Giraffe (v1.54.0). Finally, barcode signals extracted from these graph alignments are analyzed and integrated into the genotype likelihood framework to infer the most likely genotype for each inversion.

# Installating SVJedi-Tag

You can install and use the SVJedi-Tag Conda package directly.
```
conda install bioconda::svjedi-tag
```

Alternatively, you can install the dependencies manually and clone the repository from GitHub.

**Packages dependencies**
- VG toolkits (version >= 1.76.0)
- GFAGraphs (version 0.3.4) (Warning : GFAGraphs require python version 3.10 or higher and the packages networkx, tharos-pytools, matplotlib, mycolorpy)

**Download**
```

git clone https://github.com/MTemperville/SVJedi-Tag.git

git clone git@github.com:MTemperville/SVJedi-Tag.git

```
conda create -n svjedi-tag python=3.12

# Using SVJedi-Tag

### Intput files


* Linked-reads file (.fastq /.fq /.fastq.gz /.fa.gz)
* Variant calling file (.vcf)
* Reference genome file (.fasta/.fa)

### File specificities : 
#### Linked-read file requirement (FASTQ)

The sequence of each read should not contain the barcode sequence. The barcode information must be present in the header of each read in the following format (tabulation btween the header and the barcode): `@header       BX:Z:XXXX`

If the read contains a barcode validity tag (`VX:i:`), it will be taken into account, and only reads with `VX:i:1` will be processed.

#### Variant calling file (VCF)
The file must contain the inversions to be genotyped. It may also contain other types of structural variants that could have an impact on the genotyping of the inversions because of their position close to the breakpoints of the inversions.

The file must be a tabulated file with a standart vcf format. Structural variant must have the `CHROM` and `POS` fields defined (the chromosome names must be the same in the reference genome and the variant file). The `SVTYPE` and `END` tags must be in the INFO field (`SVTYPE=INV` for inversion and `SVTYPE=DEL`, `SVTYPE=INS` or `SVTYPE=BND` for other).

*Example:* 
```
#CHROM	POS	ID	REF	ALT	QUAL	FILTER	INFO
Chr1	1173997	INV1	N	<INV>	.	.	END=2173996;SVTYPE=INV;SVSIZE=1000000
Chr1	2287235	INV2	N	<INV>	.	.	END=3287234;SVTYPE=INV;SVSIZE=1000000
Chr1	4393271	INV3	N	<INV>	.	.	END=5393270;SVTYPE=INV;SVSIZE=1000000
...
```

## Command line and parameters

```
svjedi-tag run -v inversions.vcf -r reference_genome.fasta -q linked-reads.fastq -o output_path/prefix
```

If you alredy have the variation graph (GFA) generated by SVJedi-Tag and the alignment file (GAF) genetared by VG Giraffe, you can directely run de genotype prediction step:
```
svjedi-tag predict --gfa variation_graph.gfa --gaf alignment_file_vgGiraffe.gaf -v inversions.vcf -r reference_genome.fasta -q linked-reads.fastq -o output_path/prefix
```

### Parameters
```
options:
  -h, --help                           Show this help message and exit
  
  -v, --vcf             [Requiered]    VCF file containing the target inversions to genotype.
  -r, --reference       [Requiered]    Reference genome file.
  -q, --linked_reads    [Requiered]    Interleaved linked-read FASTQ file or two paired-end FASTQ files [Interleaved linked-read FASTQ file or two paired-end FASTQ files ...]
  -o, --prefix          [Requiered]    Output path and/or prefix
  

  --regionSize           [Default=10000]                Signal barcode region size (default = 10kp).
  --inaccuracy           [Default=0]                    Breakpoint inaccuracy tolerance (bp).
  --likelihood_MinDiff   [Default=20]                   Minimum difference between the two bigger genotype likelihood.
  --likelihood_ProbError [Default=0.2 0.1 0.02 0.008]   Genotype likelihood probability error according to inversion size (Low (<25kb), Medium (25kb<=...<50kb), High (50kb<=...<100kb), Very high (>=100kb)) 
  
  --gaf    GAF alignment file of linked reads against the graph (output of vg giraffe).
  --gfa    GFA graph file generated by SVJedi-Tag.
  
  --threads    [Default=1]    Number of threads
 ```
 
 #### Genotype likelihood callibration
Genotyping uses a genotype likelihood formula that takes an error probability as a parameter. This error probability has been set based on inversion sizes, and we recommend using the default error probabilities.
However, it can be modified using the `--likelihood_ProbError` parameter and estimated as follows:
```
svjedi-tag likelihood-calibration --gaf <GAF file> --gfa <GFA file> -w <Windows size>

Option:
--gaf    [Requiered]    Alignement file out of SVJedi-Tag
--gfa    [Requiered]    Variation file out of SVJedi-Tag
-w    [Requiered]    Window size (bp) for which we want to estimate the error rate 

-n   [Default=100]  Number of windows use to estimate error probability 
-ri  [Default=10000]    Region size in the windows used to estimate the error probability (according to the SVJedi-Tag method)
-ro  [Default=10000]    Region size around the windows used to estimate the error probability (according to the SVJedi-Tag method)
-p path/plot.png

```

*You can then rerun SVJedi-Tag (with gfa and gaf in input), taking into account your estimated error probability values for the following size ranges: (Low (<25 kb), Medium (25 kb ≤ ... < 50 kb), High (50 kb ≤ ... < 100 kb), Very high (≥ 100 kb)).*

## OUTPUT

#### Output VCF 
SVJedi-Tag's output is a vcf file containing all the input inversions associated to their genotype. It contains a *SAMPLE* column containing the predicted genotypes and genotyping information.

- GT : Genotype, assuming a diploid individual: either `0/0`, `0/1`, or `1/1`. A `./.` value indicates a missing value due to an insufficient number of informative barcodes in the breakpoint regions.
- DP : Total number of distinct barcodes in the breakpoints regions
- AD : Number of barcodes supporting the absence of the inversion, Number of barcodes supporting the presence of the inversion, Number of non-informative barcodes.
- PL : Phred-scaled likelihood 

#### GFA file
The GFA file contains the graph (in GFA format) constructed from the reference genome and the intput VCF file. It can be used to restart SVJedi-Tag by skipping the graph creation step.
#### GAF file 
The GFA file is the VG Giraffe output file (in GAF format), it contains the read alignments to the graph. It can be used to restart SVJedi-Tag by skipping the alignment step.

# LR_Stats

**LR_Stats** is a method for analyzing the characteristics of linked-reads data, which provides information such as: the length of the long DNA molecule, the number of molecules, the number of reads per molecule, the number of barcodes per molecule, etc.

This method is based on the analysis of barcode signals to reconstruct the original long DNA molecule. The assumption is that two reads sharing the same barcode but separated by 100 kb or more belong to two different molecules (configurable value `-s <molecule_max_size>`).

### Installation 

LR_stats and all its dependencies are installed by default when you install SVJedi-Tag.

### Run
The intput file is a alignment file (.bam).
```
svjedi-tag lr-stats -b <sort_bam_file> -o <output_path/prefix>
```

### Output LR_Stats
The output from LR_Stats consists of: a table (.csv) containing statistics on your data, and a set of plots.

**Statistics**
***Raw data***: Statistics on the raw data without creating the long DNA molecule
***Creating molecules without filtering***: Statistics derived from long DNA molecules reconstructed from all the reads in the alignment file (.bam)
***Creating molecules with more than 3 reads***: Statistics derived from reconstructed DNA molecules containing at least 3 reads, excluding all molecules consisting of a single pair of reads.
